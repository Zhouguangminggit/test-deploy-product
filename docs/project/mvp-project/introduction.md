# 项目介绍


技术栈

    后端：Python 3.12 + Django 5.2 + Celery + Redis
    前端：Tailwind CSS v4 + DaisyUI + vue + html + js
    数据库：开发环境 SQLite / 生产环境 MySQL
    部署：Docker Compose + Gunicorn + WhiteNoise

工具

    代码管理工具：Git
    Python 包管理：uv
    开发工具： VS Code、 Codex、 qoder


项目环境要求：

    Python 3.12+
    uv
    Node.js 22+
    Git（主要用于代码版本控制）


项目功能描述

    管理员
        登录、个人信息、修改密码
        用户管理：管理所有注册用户信息，查看信用等级、交易偏好、违规记录
        分类管理：管理全站商品分类、论坛板块等基础分类信息
        商品管理：管理所有用户发布的二手商品，审核上下架
        订单管理：管理所有订单信息，查看交易状态
        评价管理：管理用户对卖家的评价，处理违规评价
        论坛管理：管理论坛板块和用户发布的帖子，审核违规内容
        私信管理：查看和处理用户私信举报
        举报治理：处理用户举报的商品、帖子、用户等，决定处置方式
        帮助中心：维护帮助分类和帮助文章
        海报运营：管理首页轮播海报、公告信息
        通知管理：向指定用户或全站发送系统通知
        操作日志：查看系统关键操作记录，审计可追溯

    用户
        注册、登录、个人信息、修改密码、设置交易偏好
        首页：海报轮播 + 公告 + 热门商品 + 推荐商品 + 论坛热帖 + 帮助入口
        二手集市：浏览所有二手商品，支持按分类、关键词搜索、按热度/时间/价格排序
        商品详情：查看商品详情、卖家信息、历史评价，可收藏、私信卖家、下单购买
        我的发布：管理自己发布的商品，新增、编辑、下架、重新上架、删除
        我的订单：作为买家查看订单状态（待付款/待发货/已发货/已签收），可签收、评价；作为卖家查看买家订单，处理发货
        我的收藏：浏览已收藏的商品，可取消收藏
        校园论坛：浏览论坛板块，查看帖子列表和详情，发布、编辑、删除自己的帖子，点赞、留言
        私信：围绕商品与卖家/买家一对一沟通，支持发送举报
        消息通知：查看系统通知和业务事件通知（订单状态变更、帖子回复、评论点赞等）
        举报中心：对违规商品、帖子、用户发起举报，查看自己的举报处理进度
        帮助中心：浏览帮助分类和帮助文章，了解平台规则
        卖家主页：查看某卖家的全部在售商品和历史评价


创新设计
    协同过滤算法个性化推荐（ItemCF 离线计算 + 热度兜底）
    现代化Tailwind CSS v4 设计，精美界面
    多角色权限控制（管理工作人员、普通用户、卖家、买家等）
    异步任务与定时调度（Celery + django-celery-beat）
    买卖双方站内双向沟通
    模拟交易场景，接入模拟支付
    操作审计自动记录（管理人员可查看系统用户关键写操作）
