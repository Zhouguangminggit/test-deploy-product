# 图形设计


## 架构图提示词

### 1. 总体技术架构图（分层架构）

```text
title 校园二手平台系统架构图

layer 前端UI
    Vue / HTML / JavaScript / Tailwind CSS v4 / DaisyUI

layer 展示层
    用户前台 / 管理后台 / 卖家主页 / 个人中心

layer 业务服务
    group 核心交易 { 商品服务 / 订单服务 / 评价服务 / 模拟支付 }
    group 社区互动 { 校园论坛 / 私信服务 / 举报治理 }
    group 内容运营 { 分类标签 / 海报运营 / 帮助中心 / 站内通知 }
    group 智能推荐 { ItemCF协同过滤 / 相似度计算 / 热度榜兜底 }

layer 数据存储与缓存层
    Redis缓存与消息队列 / MySQL数据库 / SQLite数据库 / 媒体文件存储

side 公共支撑
    span 展示层 - 业务服务
    统一身份认证
    操作审计日志
    文件上传管理
    异步任务调度
    静态资源托管
    部署运维
```

### 2. 系统功能模块图

> 提示词：

绘制一张"校园二手交易平台"系统功能模块图（树状结构图），根节点为"校园二手平台"，向下分出两大分支："管理员端"与"用户端"，各分支再展开为功能叶子节点，采用自上而下的层级树形图，节点为圆角矩形，两级用不同深浅的蓝绿色区分，连线为带拐角的直角线，白底简洁风格。

- 管理员端分支：登录、个人信息、用户管理、分类管理、商品管理、订单管理、评价管理、论坛管理、私信管理、举报治理、帮助中心、海报运营、通知管理、操作日志。
- 用户端分支：注册、登录、个人信息、修改密码、首页、二手集市、商品详情、我的发布、我的订单、我的收藏、校园论坛、私信、消息通知、举报中心、帮助中心、卖家主页。
