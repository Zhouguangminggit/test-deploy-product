# 站点品牌与页脚

- `SITE_NAME` 统一前台导航、页脚和后台品牌标题。后台首页固定显示「首页」，不随站点名变化。
- `SITE_LOGO` 接受完整 URL、站点根路径或相对于 `static/` 的文件路径。前后台共用同一 URL；留空时显示站点名称首字。
- `SITE_DESCRIPTION` 用作默认页脚的站点简介。默认页脚只链接已提供的页面，并按登录状态显示账户入口。
- 产品主题全部业务批次完成后，再按实际功能和访问对象定稿页脚：可直接调整 `templates/includes/footer.html`，或覆盖前台布局的 `footer` 块。参照 [DaisyUI Footer](https://daisyui.com/components/footer/) 选择结构，保持手机纵向、宽屏横向，并沿用语义颜色与真实路由。

本次变更只涉及界面与环境配置读取，没有新增模型、业务记录或依赖种子数据的图片资源。品牌图片由部署配置或项目静态资源提供。

本地 `make run` 会先构建样式；服务运行中修改模板或 CSS 时，可用 `make css` 重新构建，或开启 `make css-watch`。开发服务从当前静态文件目录读取构建产物，生产仍由镜像构建和带哈希的静态文件清单提供样式。

Celery 结果的简体中文菜单和模型名称由项目翻译目录提供。编辑 `locale/zh_Hans/LC_MESSAGES/django.po` 后，用 `msgfmt` 重新生成同目录的 `django.mo`，两个文件随源码交付。该变更只影响显示，不改变任务结果模型或种子数据。
